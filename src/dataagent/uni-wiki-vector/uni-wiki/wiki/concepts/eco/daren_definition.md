# 电商达人（卖家）核心概念

## 基本概念

在DataSky电商体系中，**达人**即**卖家**，是指在DataSky平台上通过直播、短视频等内容形式销售商品的内容创作者。

| 概念 | 说明 |
|------|------|
| **达人ID / 卖家ID** | 平台唯一数字标识，是所有分析的入参基础 |
| **粉丝数** | 达人在DataSky平台上的粉丝总数 |
| **L分层** | 达人层级，L0-L4，L4为头部达人 |
| **UA对** | User-Author（用户-作者）对，当日卖家和买家组成关系对，跨日可重复计数 |

---

## 达人分型体系

### 运营分型（一级标签）

由平台基于达人经营数据自动打标，反映达人主要经营场域：

| 分型 | 说明 | 判断依据 |
|------|------|---------|
| **直播型** | 主要依靠直播带货 | 直播GMV占总GMV≥50% |
| **短视频型** | 主要依靠短视频带货 | 短视频GMV占总GMV≥50% |
| **泛货架型** | 主要依靠货架场经营 | 泛货架GMV占总GMV≥50% |
| **全域型** | 多场域均衡经营 | 无单一场域占比≥50% |

### 商业化分型（基于投流意愿）

| 分型 | 商业化货币化率 | 含义 |
|------|-------------|------|
| 投流意愿较强 | >20% | 大量使用商业化工具投流 |
| 投流意愿显著 | 5%~20% | 有一定投流行为 |
| 投流意愿较弱 | 0%~5% | 几乎不投流 |
| 非付费私域型 | =0% | 完全依赖自然流量 |

## U分层

用户U分层表示电商购买力分级：

| 分层 | 含义 |
|------|------|
| **U4+** | 最高层级，高购买力用户 |
| U3 | 较高购买力 |
| U2 | 中等购买力 |
| U1 | 初级购买力 |
| U0 | 流失用户/低活跃 |

---

## 货盘分型

| 分型 | 说明 | 健康占比标准 |
|------|------|------------|
| **利润品** | 高毛利商品，提升盈利能力 | <10%偏低，10-30%正常，>30%优秀 |
| **流量品** | 引流商品，吸引关注 | <10%偏低，10-20%正常 |
| **规模品** | 冲量商品，提升GMV规模 | - |
| **常规品** | 普通商品 | >80%过高，结构单一 |

---

## 二创经营

**二创**（二次创作）：卖家签约的**剪辑手**基于卖家授权的商品独立制作短视频，产生的GMV计入达人的**二创支付GMV**。

- 剪辑手人数：当期为卖家进行二创的人数
- 二创GMV：剪辑手经营产生的GMV，是总支付GMV的四大子项之一
