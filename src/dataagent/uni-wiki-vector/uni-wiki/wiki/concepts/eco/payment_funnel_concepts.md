# 电商支付链路核心概念

## 支付全链路漏斗

```
收银台曝光 → 默选曝光 → 默选采纳下单 → 下单 → 首次支付 → （失败）→ 二次支付 → 支付成功
```

---

## 核心概念定义

### 收银台

用户在DataSky电商下单时的支付界面，是所有支付行为的入口。

### 默选（默认选中支付方式）

**默选**：系统为用户预先选中的支付方式（如银行卡/微信/支付宝），用户无需手动切换。

| 指标 | 含义 |
|------|------|
| **默选曝光PV** | 收银台曝光时，默选方式出现在用户面前的次数 |
| **默选曝光率** | 默选曝光PV / 收银台曝光PV |
| **默选采纳下单订单量** | 用户使用默选方式完成下单的订单数 |
| **默选曝光采纳下单率** | 默选采纳下单 / 默选曝光PV |

## 支付漏斗层级（字母标注体系）

| 字母 | 指标名称 | 公式 | 说明 |
|------|---------|------|------|
| **A** | 下单订单量（渠道首次归因分母）| a+b | 总下单量（首次） |
| **a** | 首次支付成功订单量 | - | 第一次尝试支付成功 |
| **b** | 首次支付失败订单量 | c+d | 第一次尝试支付失败 |
| **c** | 流失下单订单量 | - | 支付失败后未二次下单 |
| **d** | 二次下单订单量 | e+f | 支付失败后发起二次支付 |
| **e** | 二次支付成功订单量 | - | 二次尝试支付成功 |
| **f** | 二次支付失败订单量 | - | 二次尝试支付失败 |
| **B** | 支付成功订单量 | a+e | **最终支付成功**（高亮核心指标）|

## 支付效率指标（字母标注）

| 字母 | 指标名称 | 公式 | 含义 |
|------|---------|------|------|
| **g** | 首次支付成功率 | a/A | 第一次尝试就成功的比例 |
| **h** | 首次支付失败率 | b/A | 第一次支付失败比例 |
| **i** | 下单订单流失率 | c/b | 失败后放弃二次支付比例 |
| **j** | 二次下单率 | d/b | 失败后发起二次支付比例 |
| **k** | 大盘二次支付成功率 | e/A | 二次支付在总下单中的成功率 |
| **m** | 二次支付失败率 | f/d | 二次支付也失败的比例 |
| - | **首次归因支付成功率** | - | 核心监控指标 |

## 支付渠道分类

### WBR 组合渠道

| 渠道 | 说明 |
|------|------|
| **微信现付** | 微信支付（即时） |
| **支付宝现付** | 支付宝支付（即时） |
| **银行卡现付** | 银行卡直接支付 |
| **后付** | 先用后付（含自有/支付宝/微信后付）|
| **月付** | 按月付款 |
| **分期** | 分期付款 |
| **其他** | 其他支付方式 |

### 头达家族类型（影响支付渠道结构）

| 家族ID | 名称 | 支付宝占比 | 微信占比 | 分期占比 | 客单价 | 特征 |
|--------|------|-----------|---------|---------|-------|------|
| 0 | 无家族 | 33% | 48% | 0.8% | 52元 | 普通用户/中小主播 |
| 1 | **辛选** | 47% | 21% | 11.7% | 272元 | 高客单价、支付宝偏好、3000元+订单多 |
| 2 | **蛋蛋** | 49% | 25% | 14.0% | 199元 | 中高客单价、分期需求高 |
| 3 | **四合** | 40% | 40% | 0.7% | 97元 | 银发族(60岁+占40%)、微信支付偏好 |
