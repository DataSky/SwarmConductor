# 外混排/单列混排核心概念

## 什么是混排

**混排**（混合排序）是DataSky推荐系统中将**多种营收业务内容**（电商、商业化、直播等）在同一推荐流中**竞争展示位置**的机制。

**单列外混排**：在单列信息流中，各业务方的内容共同参与竞争，争夺有限的展示"坑位"。

---

## 关键术语

### 流量类型分类

| 流量类型 | 简称 | 含义 |
|---------|------|------|
| **电商链路流量** | 4pp | 属于电商业务的推荐流量（含电商1pp和电商短视频）|
| **全部流量** | 联合流量 | 单列发现页所有流量，不区分业务类型 |
| **电商1pp** | 1pp | 电商商品直接推荐（直播间/商品卡）|
| **电商短视频** | 短视频 | 挂车短视频推荐 |

### 用户分层

| 分层 | 含义 |
|------|------|
| **U分层** | 用户电商购买力分级（U0-U4+），U4+为最高购买力 |
| **U4混排** | 针对高价值用户（U4+）的混排分析视角 |

---

## 混排竞争漏斗

```
内容池 → 返回量（召回）→ 参竞量 → 竞得量 → 最终曝光（竞胜量）
```

| 环节 | 说明 |
|------|------|
| **返回量** | 从召回池中返回的候选内容数量 |
| **参竞量** | 实际进入竞价的内容数量 |
| **竞得量** | 在竞价中胜出的内容数量 |
| **竞胜量（LOAD）** | 最终获得曝光位置的内容数量 |

---

## 混排打分体系

混排竞价分数由多个因子组成：

| 分数类型 | 含义 |
|---------|------|
| **竞价分（CPM/GPM分）** | 综合预估收益分，决定最终竞胜排名 |
| **ue分** | 用户体验因子分，影响内容质量权重 |
| **bonus** | 额外加分，平台对特定内容/业务的流量补贴 |
| **赋分** | 平台对某类内容的主动打分干预 |
| **gpm** | 每千次曝光预估GMV（电商内容核心指标）|

## 分析视角

### 各业务视角（4个子模块）
- 各业务 LOAD 趋势
- 各业务混排竞争过程和通过率
- 各业务混排 bonus 表现
- 各业务混排打分表现

### 电商视角（3个子模块）
- 电商 1pp 和电商短视频竞争过程和通过率
- 电商 1pp 和电商短视频 bonus 表现
- 电商 1pp 和电商短视频打分表现
