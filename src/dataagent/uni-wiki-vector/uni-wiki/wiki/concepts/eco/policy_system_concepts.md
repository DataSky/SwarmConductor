# 电商政策体系概念

## 政策体系总览

DataSky电商政策体系分为两大类：**B 补**（面向商家的补贴）和 **C 补**（面向消费者的补贴）。

| 类别 | 全称 | 受益方 | 说明 |
|------|------|-------|------|
| **B 补** | 商家侧补贴（B-side Subsidy）| 商家（卖家）| 平台给予商家的流量、资金、资源补贴 |
| **C 补** | 消费者侧补贴（C-side Subsidy）| 消费者（买家）| 平台给予消费者的优惠券、红包等 |

---

## 两种分析视角

### 运营视角

**定位**：分析商家运营人员（小二）所负责的政策整体情况

**分析内容**：
- B 补报名情况 + 任务完成情况 + 奖励发放情况
- C 补参与情况 + 效果分析 + ROI 评估

**触发方式**：用户提供小二姓名（如"诊断张三的政策情况"）

**输入要素**：
- 商家运营小二姓名（用于筛选该小二负责的商家）
- 时间范围（默认最新分区/上月）

### 资管视角

**定位**：分析电商预算使用情况（预算部门视角）

**分析模块**：
1. **预算使用**（9步分析）：预算消耗分布、消耗进度、分渠道拆解
2. **预算使用效果**（5步分析）：GMV 产出、订单量、买家数
3. **预算 ROI**（5步分析）：各补贴的 ROI 测算与对比

---

## 政策关键概念

| 概念 | 说明 |
|------|------|
| **预算消耗** | 当期政策实际花出去的补贴金额 |
| **预算效果** | 政策带动的 GMV 增量、订单量增量 |
| **预算 ROI** | 预算效果 / 预算消耗，衡量补贴投入产出比 |
| **报名率** | 符合条件的商家中实际报名政策的比例 |
| **任务完成率** | 报名商家中完成政策任务目标的比例 |
| **奖励发放** | 完成任务后平台发放给商家的奖励金额 |
