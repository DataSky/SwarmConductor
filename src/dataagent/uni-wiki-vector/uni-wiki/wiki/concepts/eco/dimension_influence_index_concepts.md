# 维度影响指数算法：TOP 影响维度识别

## 算法定位

**维度影响指数**（Dimension Influence Index）用于衡量各维度的**分布变化差异**，快速定位导致指标变化的根因维度。

---

## 适用场景

| 适用 | 不适用 |
|------|-------|
| 计数类指标（订单数、用户数）| 均值/比率类指标（→ 用综合贡献度）|
| 求和类指标（GMV、销售额）| - |
| 多维度根因定位 | - |

---

## 算法原理

**核心思想**：如果某维度的分布（各因子占比）在本期相比基期发生了显著变化，则该维度分布变化越大，越可能是指标变化的根因。

**数学本质**：基于 JS 散度（Jensen-Shannon Divergence）的变体，衡量两个分布之间的差异。

---

## 计算公式

### Step 1：计算各维度因子的占比

```
基期占比：p⁰ₐᵢ = 维度因子 i 的基期值 / 基期总值
本期占比：p¹ₐᵢ = 维度因子 i 的本期值 / 本期总值
```

### Step 2：计算变化差异值

```
sₐᵢ = p¹ₐᵢ × log₂(2 × p¹ₐᵢ / (p⁰ₐᵢ + p¹ₐᵢ))
```

**变量说明**：
- `p¹ₐᵢ`：维度因子 aᵢ 的本期占比
- `p⁰ₐᵢ`：维度因子 aᵢ 的基期占比
- `sₐᵢ`：变化差异值（越大说明该因子分布变化越显著）

### Step 3：聚合为维度差异

```
维度 a 的差异 = Σᵢ |sₐᵢ|（该维度所有因子的差异绝对值之和）
```

### Step 4：归一化得到影响指数

```
总差异 = Σₙ 维度差异ₙ（所有维度的差异之和）
维度 a 的影响指数 = 维度差异ₐ / 总差异 × 100%
```

> ⚠️ 所有维度的影响指数之和 = 100%

### 均值指标的特殊处理

对于均值类指标，需先**加权**再计算：
```
加权值 = 原始值 × 权重
然后按原子类指标方法计算
```

## 输出格式

```
维度名称          影响指数    排名
---------------------------------
用户U分层         33.13%     1    ← 最主要根因维度
一级场域类型      31.99%     2
用户年龄段        20.71%     3
订单价格带        14.17%     4
---------------------------------
合计             100.00%
```

---

## 结果解读

| 影响指数范围 | 解读 | 建议 |
|------------|------|------|
| **> 50%** | 该维度分布变化显著，很可能是主要根因 | 重点分析 |
| **20%-50%** | 该维度有一定影响，可能是次要因素 | 辅助分析 |
| **< 20%** | 该维度分布相对稳定，影响较小 | 通常不是主因 |

---

## 使用注意

> ⚠️ TOP1 维度不一定是**唯一**根因，多个维度可能存在关联关系

> ⚠️ 需要有基期和本期对比数据，且口径保持一致（同时段长度）

> ⚠️ 数据量过小时结果不稳定
