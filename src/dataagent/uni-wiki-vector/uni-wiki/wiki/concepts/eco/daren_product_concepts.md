# 达人货盘核心概念

## 货盘基础概念

| 概念 | 说明 |
|------|------|
| **货盘** | 达人带货的商品集合，包含上架商品和讲解商品 |
| **SPU** | Standard Product Unit，标准产品单元，同类商品的标识 |
| **同品ID** | 相同商品的**跨店标识**，用于复购分析（不同店铺同款商品共享同品ID） |
| **爆品** | 带货GMV排名靠前、转化率高的商品 |
| **个人爆品** | 达人自己直播中的GMV爆品 |
| **平台爆品** | 全平台热销的爆品（非单一达人数据）|

---

## 讲品效率指标

| 指标 | 说明 | 健康标准 |
|------|------|---------|
| **上架商品数** | 直播期间上架的商品总数 | - |
| **讲解商品数** | 主播实际讲解过的商品数量 | - |
| **讲解商品数占比** | 讲解商品数/上架商品数 | <40%偏低，>60%良好 |
| **讲解商品时长** | 讲解商品的累计时长 | - |
| **直播动销商品数** | 实际产生销售的商品数量 | - |
| **动销率** | 动销商品数/上架商品数 | 越高越好 |

---

## 货盘分型体系

| 分型 | 说明 | 健康占比 |
|------|------|---------|
| **利润品** | 高毛利商品，提升盈利能力 | <10%偏低，10-30%正常，>30%优秀 |
| **流量品** | 低价引流商品，吸引用户进入 | <10%偏低，10-20%正常 |
| **规模品** | 冲量商品，提升整体GMV规模 | - |
| **常规品** | 普通商品，无特殊定位 | >80%过高说明结构单一 |

---

## 商品转化效率指标

| 指标 | 说明 |
|------|------|
| **直播支付用户转化率** | 在直播间看到商品后最终付款的用户比例 |
| **商品CTR** | 商品在直播间的点击率 |
| **商品CVR** | 商品点击后的购买转化率 |
| **GPM** | 每千次曝光产生的GMV（Gross Per Mille）|
| **讲解时长占比** | 讲解商品时长/总直播时长 |

---

## 同品复购率（4维度）

复购分析基于**同品ID**（跨店同款），统计买家在不同时间窗口内再次购买的比例：

| 时间窗口 | 说明 |
|---------|------|
| **7天复购率** | 购买后7天内再次购买的比例 |
| **14天复购率** | 购买后14天内再次购买的比例 |
| **21天复购率** | 购买后21天内再次购买的比例 |
| **30天复购率** | 购买后30天内再次购买的比例 |

**复购类型判断**：

| 类型 | 特征 | 含义 |
|------|------|------|
| ⚡ 快速复购型 | 7天复购率高，7-30天无明显增长 | 用户决策快，商品复购性强 |
| 📅 中期决策型 | 14-21天复购高峰 | 用户需要时间决策 |
| 🌱 长期种草型 | 21-30天仍有增长 | 慢热型商品，需持续种草 |
| ❌ 无复购 | 30天复购率=0 | 一次性消费商品 |

## 商品用户效率维度（8维度）

分析买家与粉丝关系、购买行为：

| 是否粉丝 | 买家类型 | 数量 |
|---------|---------|------|
| 粉丝 | 回流买家 | 高价值 |
| 粉丝 | 新买家 | 首次转化 |
| 粉丝 | 活跃买家 | 持续购买 |
| **粉丝** | **未成交用户** | 关键漏损 |
| 非粉丝 | 回流买家 | 公域高价值 |
| 非粉丝 | 新买家 | 新客拓展 |
| 非粉丝 | 活跃买家 | 公域活跃 |
| **非粉丝** | **未成交用户** | 公域漏损 |

> ⚠️ **未成交用户分析是关键**：大量曝光未转化=流量浪费，需分析原因（价格带不匹配/商品吸引力不足等）
