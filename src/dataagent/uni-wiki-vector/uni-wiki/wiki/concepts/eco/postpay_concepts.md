# 先用后付（后付）核心概念与指标体系

## 什么是先用后付

**先用后付**（Buy Now Pay Later，BNPL）是用户先收到商品、后在约定时间内还款的支付方式。

---

## 后付三大渠道

| 渠道 | 说明 |
|------|------|
| **自有后付** | DataSky自建的后付产品 |
| **支付宝后付** | 支付宝蚂蚁花呗等后付产品 |
| **微信后付** | 微信分付等后付产品 |

> ⚠️ 三渠道用户存在**重叠**，各渠道数值不可加总得整体。整体渗透率 = 三渠道渗透率之和。

---

## 六大核心模块

### 1. GMV 渗透率

| 指标 | 说明 |
|------|------|
| **整体后付GMV渗透率** | 三渠道渗透率之和（不可直接查，需分渠道查后加总）|
| 各渠道渗透率 | 后付GMV / 总支付GMV |

### 2. D90 资损率

**定义**：逾期超过90天确认金额 / 总确收金额

**关键特征**：
- 基于**签收日期**计算（非支付日期）
- 订单签收后需满**90天**才可见最终数据
- 最新签收日期 ≈ 当前日期 - 92天（90天观测期 + 2天处理延迟）

> ⚠️ **绝对不能**用分区时间聚合D90资损率（会返回0或"-"），必须展开签收日期维度查询

### 3. 获客指标

| 指标 | 类型 | 含义 |
|------|------|------|
| **后付新签用户数** | 流量型（日均）| 新注册后付的用户 |
| **后付首付买家数** | 流量型（日均）| 首次使用后付完成支付的用户 |
| **电商DAC** | 截面存量（日均）| 后付可用（Dayactive Customer）用户 |
| **后付存量签约用户数** | 截面存量（日均）| 已签约后付的用户总量 |
| **后付准入用户数** | 截面存量（日均）| 平台审核通过可使用后付的用户 |

**关键率值**（需手动计算）：
- DAC签约率 = 存量签约日均 / DAC日均
- DAC准入率 = 准入日均 / DAC日均
- 准入签约率 = 存量签约日均 / 准入日均

### 4. 使用指标

| 指标 | 含义 |
|------|------|
| **签约使用率(UV粒度)** | 签约用户中实际使用后付支付的比例 |
| **签约可用率(UV粒度)** | 签约用户中额度可用的比例 |
| **曝光使用率(UV粒度)** | 收银台看到后付选项的用户中使用的比例 |
| **曝光默选率(UV粒度)** | 后付出现在默选位置的概率 |
| **默选采纳率(UV粒度)** | 默选后付时用户采纳（不切换）的比例 |
| **非默选采纳率(UV粒度)** | 未默选时用户主动选择后付的比例 |

### 5. ARPU 倍比

**定义**：使用后付的用户 ARPU / 使用其他支付方式的用户 ARPU

- > 1：后付用户人均消费高于非后付用户（后付有带动消费升级效果）
- < 1：后付用户人均消费低（需关注用户质量）

**数据来源**：`先用后付-使用`数据集（不要用Hive表，口径不同）

### 6. 支付宝后付订单量

独立统计口径，按日均展示。

---

## 数据类型处理规则

| 数据类型 | 示例 | 处理方式 |
|---------|------|---------|
| **率类** | GMV渗透率、使用率 | 按时间段汇总查询，直接取值 |
| **量类** | 新签用户数、首付用户数 | 查7天汇总 ÷ 7 → 日均 |
| **截面存量** | DAC、存量签约、准入 | 逐日查询后取**日均值**（不用单日快照，避免周末偏差）|
| **截面率** | DAC签约率、准入率 | 日均分子 / 日均分母计算 |
| **D90资损率** | D90资损率 | 基于签收日期，取7天均值 |
